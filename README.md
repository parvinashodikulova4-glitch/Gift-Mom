# Mom Gift Website

A small responsive surprise website made with HTML, CSS and JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open the `mom-gift` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Edit the letter in `index.html` whenever you want.

## Publish
GitHub Pages generally requires a public repository on GitHub Free. If you want to keep the source private, use Vercel and import the private GitHub repository, or publish a separate public copy containing only these static files.

No build step is required. The site uses Google Fonts, so those fonts need an internet connection; fallback fonts are included.
